# カロナビ

食事・運動・体重を記録する iOS アプリです。画面は Flutter の iOS アプリです。

## アプリを見る

```bash
tool/run_ios.sh
```

release で実機に入れるときも同じスクリプトを使う。どちらもテスト用の有料／無料切替が付く。

```bash
tool/run_ios.sh --release
```

App Store 提出用の Archive はこのスクリプトを通さない。切替は付かない。
