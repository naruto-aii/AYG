# App Store Connect に入れるデータ

この表は、いまのアプリが端末の外へ送り、アカウントと一緒に保存しているデータです。追跡用のコードはありません。`NSPrivacyTracking` は false です。

UserDefaults は2通りです。アプリ自身の保存は `CA92.1` です。ウィジェットと Siri が使う App Group `group.com.narutoaii.ayg` の保存は `1C8F.1` です。ウィジェット拡張は同じ App Group の UserDefaults だけを使うので、理由は `1C8F.1` だけです。

| App Store の種類 | ユーザーに紐づく | 目的 | コードで見ているもの |
| --- | --- | --- | --- |
| メールアドレス | はい | アプリの機能 | Google または Apple でログインし、Supabase のユーザーのメールを設定画面に出します。 |
| ユーザーID | はい | アプリの機能 | 同期する行は `user_id` に Supabase のユーザーIDを付けます。 |
| 健康 | はい | アプリの機能 | HealthKit から生年月日、性別、身長、体重を読みます。プロフィールとして `profiles` に保存します。体重のスナップショットは `health_snapshots` にも保存します。書き戻す処理はありません。 |
| フィットネス | はい | アプリの機能 | HealthKit のアクティブエネルギーは `health_snapshots` に保存します。自分で記録した運動は `exercise_entries` に保存します。HealthKit のワークアウトは端末内の保存だけで、同期していません。 |
| その他のユーザーコンテンツ | はい | アプリの機能 | 食事、アルコール、保存食品、食事テンプレート、運動テンプレート、公開食品、評価、通報を、そのユーザーの行として保存します。保存食品にはバーコードを入れられます。 |

バーコード検索は、番号だけを Open Food Facts に送ります。その通信にユーザーIDは付けていません。カメラの画像を保存したり送ったりする処理はありません。

## 要確認

次の行は、コードだけでは App Store Connect のチェックを決められません。

| データの種類 | 判定 | 決められないこと |
| --- | --- | --- |
| 名前 | 要確認 | Sign in with Apple は `fullName` を要求します。アプリは `givenName` と `familyName` を読まず、Supabase にも渡しません。名前を収集データにするかは、ここで決めてください。 |
| 性別を機微な情報にするか | 要確認 | 性別は HealthKit の `GENDER` とプロフィールの `gender` として保存しています。上の表では健康に入れています。別に「機微な情報」へ入れるかは、ここで決めてください。 |
| 検索履歴 | 要確認 | 食品成分表の検索語は `search_official_foods` に送ります。検索語を保存するテーブルはありません。サーバのログに残す運用かは、コードにありません。 |
| 購入履歴 | 要確認 | カロナビ+の期限は端末の SharedPreferences（`calonavi_plus_expires_at_ms`）だけにあります。購入情報を Supabase へ送る処理はありません。購入履歴を申告するかは、ここで決めてください。 |
| 問い合わせ内容 | 要確認 | 設定はメールアプリを開くだけです。本文をアプリが保存する処理はありません。メールの保管を収集に数えるかは、ここで決めてください。 |
| 広告や分析 | 要確認 | 広告SDK、解析SDK、広告識別子の取得はありません。上のデータの目的を、アプリの機能以外（広告、分析）にもするかは、コードに書かれていません。 |
