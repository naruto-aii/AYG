# App Store Connect に入れるデータ

この表は、いまのアプリが端末の外へ送り、アカウントと一緒に保存しているデータです。追跡用のコードはありません。`NSPrivacyTracking` は false です。広告SDK、解析SDK、広告識別子の読み取りはありません。

使い道はアプリの機能と分析です。広告の目的には使いません。ヘルスケア由来のデータ（健康、フィットネス、そして性別）は広告に使いません。

UserDefaults は2通りです。アプリ自身の保存は `CA92.1` です。ウィジェットと Siri が使う App Group `group.com.narutoaii.ayg` の保存は `1C8F.1` です。ウィジェット拡張は同じ App Group の UserDefaults だけを使うので、理由は `1C8F.1` だけです。ウィジェット拡張はデータを端末の外へ送りません。

| App Store の種類 | ユーザーに紐づく | 追跡 | 目的 | 残す表と、コードで見ているもの |
| --- | --- | --- | --- | --- |
| 名前 | はい | いいえ | アプリの機能、分析 | 基本情報で登録するユーザー名。`profiles.display_name` がアプリの保存先です。同じ文字列だけを `account_display_names` に写し、後から人数を集計します。サインインが返した名前は、欄の初期値と、まだ名前が無いときの `user_metadata` の `full_name` だけに使います。ヘルスケアからは氏名を読みません。 |
| メールアドレス | はい | いいえ | アプリの機能、分析 | Google または Apple でログインし、`users.email` に保存します。設定画面に出します。 |
| ユーザーID | はい | いいえ | アプリの機能、分析 | 同期する行は `user_id` に Supabase のユーザーIDを付けます。 |
| 健康 | はい | いいえ | アプリの機能、分析 | HealthKit または Health Connect から生年月日、性別、身長、体重を読み、`profiles` に保存します。体重のスナップショットは `health_snapshots` と `weight_entries` にも保存します。書き戻す処理はありません。広告には使いません。 |
| 機微な情報 | はい | いいえ | アプリの機能、分析 | 性別です。保存先は健康と同じ `profiles.gender` の1列です。健康にも申告します。広告には使いません。 |
| フィットネス | はい | いいえ | アプリの機能、分析 | HealthKit のアクティブエネルギーは `health_snapshots` に保存します。自分で記録した運動は `exercise_entries` に保存します。Health のワークアウトは種目、開始、終了、消費カロリーを `health_workouts` に保存します。消費カロリーが無いときは空のままです。広告には使いません。 |
| 購入履歴 | はい | いいえ | アプリの機能、分析 | カロナビ+の商品ID、期限、状態を `calonavi_plus_entitlements` に保存します。レシート本文、検証データ、購入トークンは保存しません。購入の元になった取引の番号（original transaction id）は、`store_original_transactions` で利用者と結び、サーバーが受ける `store_server_notifications` にも保存します。生の `app_events` は 90 日で消すため、照合には使いません。 |
| 検索履歴 | はい | いいえ | アプリの機能、分析 | 食品の検索語は `food_search_queries`、運動種目の検索語は `exercise_search_queries` です。空の一覧表示は書きません。結果の栄養値や消費カロリーは入れません。 |
| 製品の操作 | はい | いいえ | アプリの機能、分析 | 画面名と操作を `app_screen_actions` に保存します。タブの表示と選択、初回の食事案内、ホームウィジェットとロック画面のボタン、共有（今日の食事）です。体重やカロリーの数値は入れません。 |
| その他のユーザーコンテンツ | はい | いいえ | アプリの機能、分析 | 食事、アルコール、保存食品、食事テンプレート、運動テンプレート、公開食品、評価、通報を、そのユーザーの行として保存します。食事が保存食品から作られたときは、その版番号を `food_entries.source_saved_food_version` に残します。保存食品にはバーコードを入れられます。 |
| 写真またはビデオ | はい | いいえ | アプリの機能 | 写真で登録で選んだ1枚を、栄養の推定のため Anthropic, PBC（米国）へ送ります。カロナビの表や Storage には保存しません。`meal_photo_analyses` に残すのはモデル、トークン、推定費用、料理名と量と補足の有無だけで、写真そのもの、料理名、量、補足の文面、栄養の中身は入れません。分析や広告には使いません。 |
| その他の使用状況データ | はい | いいえ | アプリの機能、分析 | 同意した人の操作を `app_events` に保存します。ウィジェットと Siri の操作も含みます。体重やカロリーの数値は入れません。 |
| クラッシュデータ | はい | いいえ | アナリティクス | `app_error` に、エラーの型だけを保存します。メッセージ本文は入れません。 |
| パフォーマンスデータ | はい | いいえ | アナリティクス | 画面にいた時間、起動や同期にかかった時間を `app_events` の属性として保存します。 |
| その他の診断データ | はい | いいえ | アナリティクス | 送信待ちの件数、隔離した件数、捨てた件数を `analytics_queue_health` で保存します。 |
| デバイスID | はい | いいえ | アナリティクス | インストールごとのランダムな番号（`install_id`）です。広告識別子やベンダー識別子ではありません。キーチェーンには入れません。 |
| 広告データ | はい | いいえ | アナリティクス | Apple の広告から入れたかどうかの結果だけです。広告の配信には使いません。追跡もしません。 |

バーコード検索は、番号だけを Open Food Facts に送ります。その通信にユーザーIDは付けていません。写真で登録の食事の写真は、上の表のとおり Anthropic, PBC（米国）へ送り、カロナビには保存しません。AIで探すの検索語も、栄養の推定のため Anthropic, PBC（米国）へ送ります。カロナビの食品データベースには追加しません。同じ検索の推定は `ai_food_estimate_cache` に、同じ利用者が再利用するために残します。食品の一覧には出さず、他の利用者には出しません。アカウントを削除すると消します。自炊コーチは、手元にある食材と、この食事の条件のメモを、献立の推定のため Anthropic, PBC（米国）へ送ります。同じ食材と丸めた目標の献立は `cook_coach_cache` に再利用のために残します。利用者の識別子は入れないので、アカウントを削除しても消えません。写真で登録と AIで探すの推定結果は `ai_food_result_collections` に、正規化した食品名、店名、量、カロリーとPFC、モデル、経路、保存時に直したかを残します。写真そのもの、検索語の原文、料理名や補足の原文は残しません。他の利用者の検索には出さず、アカウントを削除するまで残します。購入の署名付き取引は検証に使い、表には商品ID、期限、状態と、取引番号だけを残します。初めてこれらのAI機能を使う前に同意を取り、同意するまで Anthropic へは送りません。同意は `ai_data_consents` に、時刻と版だけを残します。アカウントを削除すると消します。

## 申告しないもの

次は、アプリが集めていないか、端末の外の表に残していないので、収集データにしません。

| データの種類 | 判定 | 実装 |
| --- | --- | --- |
| 問い合わせ本文 | 集めない | 設定はメールアプリを開くだけです。本文をアプリもサーバの表も保存しません。 |
| レシート本文と購入トークン | 集めない | 購入状態の表にあるのは商品ID、期限、状態です。レシート本文と購入トークンは保存しません。取引の番号は、上の購入履歴のとおり保存します。 |
| Sign in with Apple のリフレッシュトークン | 購入トークンではない | アカウント削除のとき Apple へ失効を頼むためだけに `internal.apple_refresh_tokens` へ保存します。アプリには返しません。購入状態、検索、画面操作、広告には使いません。削除と同時にその行も消します。 |
| 歩数 | 集めない | 読み取る型に歩数はありません。 |
| App Store Connect | アプリの画面からは取らない | 売上やダウンロード数は、このアプリからは取得しません。サーバーの `store-sales-import` と `store-analytics-import` が、社長の承認のあとで App Store Connect API から取り込みます。 |
| 広告 | 使わない | 広告SDKは入れていません。上のデータの目的に広告はありません。ヘルスケア由来のデータは広告に使いません。 |
| 共有画像の中身 | 集めない | 共有シートに渡すだけで、サーバには保存しません。保存を選んだときだけ、写真への追加をシステムが行います。食事の写真の読み取りは、上の写真またはビデオです。 |
