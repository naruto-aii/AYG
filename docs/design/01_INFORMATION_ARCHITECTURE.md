# カロナビ 画面一覧・導線・状態

機能は凍結済みです。このファイルは、デザイナーが描く画面と状態の一覧です。  
現行の画面構成は **web-preview の実装を正**とします。見た目の踏襲は不要です。

参照 Preview: https://naruto-aii.github.io/AYG/

---

## 1. 全体マップ

```text
未ログイン
  └ ログイン（Google / Apple）
       └ 初回未完了 → Health 可否 → 基本情報 → 目標
            ├ Health 利用 → ホーム
            └ Health 未使用 → 活動量 → ホーム

ログイン済み（初回完了）
  ├ ホーム
  ├ 食事
  ├ 運動
  ├ 体重
  └ 設定
```

下タブ（iPhone）と左サイドバー（広い画面）は、同じ 5 項目・同じ順番です。

| # | ラベル | 役割 |
| --- | --- | --- |
| 1 | ホーム | 今日あと何kcal と今日の記録 |
| 2 | 食事 | 食事・アルコールの日別一覧 |
| 3 | 運動 | 運動の日別一覧 |
| 4 | 体重 | 体重の一覧・追加・編集・削除 |
| 5 | 設定 | プロフィール、根拠、規約、アカウント |

タブは増やしません。履歴カレンダーはタブではなく、食事／運動／ホームから開く overlay です。

## 2. 認証

### ログイン

必須要素

- アプリ名「カロナビ」
- タグライン「毎日の食事と運動を、やさしく見える化。」
- **Googleでログイン**
- **Appleでログイン**
- 利用規約リンク
- プライバシーポリシーリンク

禁止

- ゲスト／スキップ
- メール＋パスワード新規登録の追加
- ストア名やロゴへの AYG 表示

状態

| 状態 | 内容 |
| --- | --- |
| 通常 | 2つのログインボタン |
| 読込 | いずれか押下中。二重送信しない |
| キャンセル | 何も起きない（エラーにしない） |
| 失敗 | 失敗したことと再試行。詳細な内部エラーは出さない |
| 規約リンク | 外部ページ。https://naruto-aii.github.io/AYG/legal/terms.html と privacy.html |

Web Preview 固有（本番 iPhone では主対象外）

- アプリ内ブラウザでは Google ログインが制限される場合がある
- ストレージが使えないとログイン状態を保持できない

本番デザインの主対象は iPhone です。Web 固有バナーをメインの見た目にしないでください。

## 3. 初回

順番固定。戻れるなら戻る。スキップでホームへ入る導線は作らない。

### 3.1 Health 可否

- 質問：Apple Health / Health Connect と連携するか
- 選択肢：利用する（推奨）／利用しない
- 未選択のまま次へは不可
- 端末が非対応のときは、使えない旨を出し、手入力ルートへ進める

利用する → 権限ダイアログ（OS）→ 基本情報（取れた項目は先に入っている）  
利用しない → 基本情報（空）

**Health Workout の一覧・自動取り込み画面は作らない。** ここでは可否だけです。

### 3.2 基本情報

| 項目 | 内容 |
| --- | --- |
| 生年月日 | 必須 |
| 性別 | 男性 / 女性 / その他 |
| 身長 (cm) | 必須 |
| 現在体重 (kg) | 必須。小数可 |

Health から取れた項目は先に入っている。取れなかった項目は手入力。  
「取得できなかった項目は手入力してください」を出せること。

### 3.3 目標

| 項目 | 内容 |
| --- | --- |
| 目標区分 | 減量 / 維持 / 増量 |
| 目標体重 (kg) | 必須 |
| 目標日 | 必須 |

警告（止めない。確認して保存できる）

- 減量なのに目標体重が現在体重以上
- 増量なのに目標体重が現在体重以下
- 維持なのに目標体重と現在体重に差がある
- 目標日までの期間が短い

設定画面の目標編集でも同じ警告を使います。

### 3.4 活動量（Health 未使用時のみ）

日常語で選ぶ。係数や MET の数字を主ラベルにしない。

| 表示 | 補足 |
| --- | --- |
| 座っている時間が長い | デスクワーク中心で、日中の歩行が少ない |
| 立ち仕事・歩くことが少し多い | 通勤や家事で軽い移動がある |
| 日常的によく動く | 立ち仕事や徒歩移動が日常にある |
| かなり活動的 | 日中の移動や立ち仕事が多い |
| 非常に活動的 | 肉体労働や終日の移動が多い |

完了後、ホームへ入ります。

## 5. ホーム

主役は **今日あと何kcal**。それ以外は従です。

### 置くもの

1. カロナビのマークまたは名前（AYG は出さない）
2. 今日あと ○○ kcal  
   - 超過時は「超過 ○○ kcal」。責めない
3. 目標kcal / 摂取kcal の内訳（小さく）
4. 「この数値の計算根拠」→ 当日の説明（詳細は設定の計算根拠へリンク）
5. PFC 進捗（タンパク質・脂質・炭水化物）
6. クイック追加  
   - 食事追加  
   - 運動追加  
   - 体重記録
7. 今日の食事（時刻・kcal。タップで編集、削除は確認＋Undo）
8. 今日のアルコール（別レコード。食品と混ぜない）
9. 今日の運動

補助カード（入れてもよい。主役を超えない）

- 摂取 kcal
- 消費 kcal（記録した運動）
- 現在体重
- 目標（減量／維持／増量と残り日数。期限超過の表示）

### ホームの状態

| 状態 | 内容 |
| --- | --- |
| 空 | 食事・アルコール・運動がそれぞれ 0 件。追加を促す |
| 読込 | 起動直後や再計算中 |
| エラー | データが無い／取れない。再ログインや再試行 |
| 超過 | リングや数値の色を変える。警告の赤一色で埋めない |
| 削除 | 確認ダイアログ → 削除 → 「元に戻す」 |

ホームから履歴カレンダーを開けてよい（タブ追加ではない）。

## 6. 食事

### 6.1 食事タブ

- タイトル「食事」
- 日送り（今日・昨日など）。未来日は閲覧可、**新規追加は不可**
- その日の食事一覧
- 追加メニュー：食事を追加 / アルコールを追加
- 食事テンプレート一覧へ
- 履歴カレンダーへ

空：「この日の食事記録はありません」＋ 今日以前なら「食事を追加」  
未来日：「未来の日付には記録を追加できません」

### 6.2 食事を追加 / 編集

追加手段は常に見えること。折りたたみで隠さない。

| 手段 | 内容 |
| --- | --- |
| 手入力 | 食品名、kcal、P/F/C、数量（小数可。空なら 1） |
| バーコード | **カメラ** と **番号入力** を常時表示 |
| 保存食品 | マイ食品から選ぶ |
| 公開食品 | 公開食品を検索して選ぶ |
| テンプレート | 既存テンプレートから追加、または新規作成 |

手入力フィールド

- 食品名（必須）
- カロリー・タンパク質・脂質・炭水化物
- 数量（小数可）
- 記録日時
- 任意：食品として保存（次回再利用）。公開／非公開
- 任意：入力内容をテンプレートとして保存

編集時は削除できる（確認＋Undo）。

バーコード

- カメラでスキャン
- 番号を打って検索
- カメラ不可でも番号入力だけで完了できる
- 見つからない／一部欠け → 手入力欄を残し、欠けた項目だけ埋める

数量は小数可（例: 0.5 個、1.5 杯）。

### 6.3 アルコール（別フォーム）

食品追加と混ぜない。食品マスターにも載せない。

- 飲料名
- 数量と単位
- アルコール度数 (%)
- 純アルコール量 (g)（分かれば）
- 飲料全体のカロリー（任意）
- 記録日時
- プレビュー：純アルコール、アルコール由来kcal、摂取への反映

一覧では食事と並べてもよいが、レコード種別は分ける。

### 6.4 マイ食品 / 公開食品 / テンプレート

マイ食品

- 一覧、検索、すべて／非公開／公開
- 新規作成、編集、削除
- 公開する／非公開にする（公開確認あり）
- 食事追加時に選べる

公開食品

- 食品名またはバーコードで検索
- 詳細を見て食事に追加（数量指定）
- 評価・報告などの既存サブフローは残してよい。新規コミュニティ機能は足さない

食事テンプレート

- 一覧、検索、作成、編集、削除、利用
- 利用時は数量確認画面を挟んでよい
- 元食品の状態が変わっているときの確認（使う／除外／キャンセル）

## 7. 運動

### 7.1 運動タブ

- 日送り。未来日は新規追加不可
- その日の運動一覧
- 追加、テンプレート、履歴カレンダー

空：「この日の運動記録はありません」＋ 追加

### 7.2 運動を追加 / 編集

2通り。両方デザインする。どちらか一方にしない。

1. **MET**  
   種類 → 種目 → 強度 → 時間。kcal は計算結果として見せる。  
   詳細（内部 MET、計算に使った体重）は折りたたんでよい。根拠はリンク先。
2. **手入力kcal**  
   運動名、時間、消費kcal を直接入れる。

共通

- 記録日時
- テンプレートから追加
- 入力内容をテンプレートとして保存
- 編集時は削除（確認＋Undo）

**Health Workout の自動取り込み画面は作らない。** 手動記録とテンプレートだけです。

### 7.3 運動テンプレート

- 一覧、検索、作成、編集、削除、利用
- 種目（名前、時間、任意でセット／回数／重量）

## 8. 体重

完成形を描きます。現行 Preview の「準備中」は禁止です。

### 8.1 体重タブ

- 記録の一覧（日付・体重kg・手入力／Health などの出典が分かれば出す）
- 追加
- 行タップで編集
- 削除（確認。Undo できるとなおよい）
- グラフは見た目の範囲で可。期間切替などの新機能は足さない

空：「体重記録はまだありません」＋「体重を記録」

### 8.2 体重を記録 / 編集

- 体重 (kg)、小数可。目安 30〜300
- 記録日時
- Health 同期が ON のとき、Health の値が後から優先される場合がある旨
- 保存／更新／削除

ホームの「体重記録」からも同じ画面へ。

一覧の項目と順番を守ってください。

| 項目 | 内容 |
| --- | --- |
| ログイン中 | メールなど識別子。編集画面ではない |
| 基本情報 | 初回と同じ項目を編集 |
| 目標 | 初回と同じ＋矛盾警告 |
| 活動・Health | 連携 ON/OFF、再取得、活動量（Health 未使用時） |
| マイ食品 | 6.4 と同じ一覧 |
| 計算根拠 | 推定であることの断り＋文献リンク。本文は短く |
| 利用規約 | 外部ページ。https://naruto-aii.github.io/AYG/legal/terms.html |
| プライバシー | 外部ページ。https://naruto-aii.github.io/AYG/legal/privacy.html |
| 特商法 | 外部ページ。https://naruto-aii.github.io/AYG/legal/tokushoho.html 。販売業者: 麹池成 |
| 運営連絡 | calonavi.ayg.support@gmail.com |
| サポート | 外部ページ。https://naruto-aii.github.io/AYG/legal/support.html |

- 「医療上の診断や治療を目的としたものではありません」
- 式の解説をホームに長く置かない
- 文献はリンク先

## 10. 状態カタログ（デザイン必須）

すべての主要リストとフォームで、次を描いてください。

### 空

- 今日の食事／アルコール／運動が 0 件
- その日の食事タブ／運動タブが 0 件
- 体重 0 件
- マイ食品 0 件
- テンプレート 0 件
- 公開食品の検索結果 0 件

空は「準備中」にしない。次の行動（追加、検索）を出す。

### 読込

- ログイン中
- バーコード検索中
- 公開食品検索中
- 保存／更新中
- Health 再取得中
- 初回の完了保存中

ボタンは二重送信しない見た目にする。

### エラー

- ログイン失敗
- 保存／削除／復元失敗
- バーコード取得失敗、カメラ不可
- Health 取得失敗（手入力へ誘導）
- リンクを開けない
- 再試行できること

内部の例外文をそのまま出さない。短い日本語。

### 超過

- ホームの主役数値を「超過 ○○ kcal」
- PFC 超過もバーや数値で分かる
- 責めない。赤面全体にはしない

### 削除確認 + Undo

フロー固定

1. 確認ダイアログ（タイトル「削除確認」、対象名、キャンセル／削除）
2. 削除実行
3. 「削除しました」＋ **元に戻す**
4. 復元失敗時は短いエラー

対象：食事、アルコール、運動。体重・テンプレート・マイ食品も確認は必須。Undo は記録系で揃える。

### その他

| 状態 | 内容 |
| --- | --- |
| 未来日 | 閲覧可、追加不可 |
| 目標警告 | 止めずに確認 |
| 入力エラー | 必須漏れ、範囲外、0 以下の数量 |
| 権限 | Health、カメラ。拒否しても手入力で先へ |

## 11. コピーの目安

現行実装の文言です。言い回しの改善は可。意味と項目は変えない。

- あと / 超過 / kcal
- 今日の食事 / 今日のアルコール / 今日の運動
- 食事追加 / 運動追加 / 体重記録
- Googleでログイン / Appleでログイン
- この数値の計算根拠
- 削除確認 / 元に戻す
- 未来の日付には記録を追加できません
- 医療上の診断や治療を目的としたものではありません

ストア名・アイコン・スプラッシュに AYG を使わない。

## 12. 現行 Preview との差分（デザインは要件側）

web-preview にあるが、デザインでは直すもの

| 現行 Preview | デザイン |
| --- | --- |
| 体重タブが「準備中」 | 一覧・追加・編集・削除 |
| バーコードが折りたたみ | カメラと番号を常時表示 |
| 設定に運営連絡・アカウント削除・特商法がない | 項目として置く |
| Apple ログインが未完成表示 | 通常のログイン手段として置く |
| 見た目が仮 | 踏襲不要 |

web-preview にあり、デザイン対象に含めるもの

- 5 タブと広い画面のサイドバー
- ホームの主役数値、PFC、クイック追加、今日の食事／アルコール／運動
- 食事の手入力・バーコード・保存食品・公開食品・テンプレート
- アルコール別フォーム
- 運動の MET / 手入力kcal とテンプレート
- 削除確認 + Undo
- 計算根拠画面
- 履歴カレンダー（タブではない）
