# カロナビ デザイン納品物

機能は凍結済みです。見た目の成果物だけを納品してください。  
公開目標は Apple App Store（iPhone 優先）です。Web は Preview のみです。

---

## 1. 納品の考え方

- 実装は Flutter 側が行います。デザイナーは **Figma と画像アセット** を渡します。
- コンポーネント名・余白・状態が実装者に読み取れること。
- 内側（API、メール、Flutter Environment、Apple コンソール）は納品対象外です。
- サポートメールは calonavi.ayg.support@gmail.com。公開 URL は https://naruto-aii.github.io/AYG/legal/ です。架空のアドレスは作らないでください。

## 2. Figma

### 必須

1. **iPhone メイン（優先）**  
   論理幅 390pt 前後（iPhone 14/15 クラス）。Safe Area を考慮。
2. 画面  
   [01_INFORMATION_ARCHITECTURE.md](./01_INFORMATION_ARCHITECTURE.md) の全画面。  
   最低でも：ログイン、初回 4 ステップ、ホーム、食事、食事追加、アルコール、運動、運動追加、体重一覧、体重追加、設定。
3. 状態  
   空 / 読込 / エラー / 超過 / 削除確認（Undo）を、該当画面で描く。
4. ナビゲーション  
   下タブ 5 つ。広い画面用に左サイドバー（同じ 5 つ）を 1 フレーム。
5. コンポーネント  
   ボタン（主／副／破壊）、入力、カード、リスト行、タブ、ダイアログ、Snackbar（Undo）、空／読込／エラー。
6. テキストスタイルとカラー  
   日本語 UI。医療アプリに見えないこと。
7. フロー  
   ログイン → 初回 → ホーム。ホームから食事／運動／体重。設定の各項目。

### あるとよい

- ダークモードは必須ではない。作るなら iPhone の通常モードを先に完成させる
- タブレット／Web Preview 用のサイドバー付きホーム 1 枚
- マイクロコピー案（空状態、超過、削除）

### 構成の目安

```text
カロナビ
  ├ Cover
  ├ Foundations（Color / Type / Icon / Radius）
  ├ Components
  ├ Flows
  │    ├ Auth
  │    ├ Onboarding
  │    ├ Home
  │    ├ Food
  │    ├ Workout
  │    ├ Weight
  │    └ Settings
  ├ States（Empty / Loading / Error / Overage / Delete+Undo）
  └ Store（Icon / Splash / Screenshots）
```

ページ名やフレーム名は日本語で、実装者が画面と対応できる名前にしてください。

## 3. アプリアイコン（1024）

Apple 必須の 1024×1024 px。

| 項目 | 指定 |
| --- | --- |
| ファイル | PNG、正方形、1024×1024 |
| 角丸 | 付けない（ストア側で処理） |
| 透明 | 使わない |
| 名前 | カロナビ。**AYG を出さない** |
| 文字 | 小さく「カロナビ」またはマークのみ。長文禁止 |
| トーン | 医療十字・心拍数の過剰表現は避ける |

現行の暫定アイコン文字「カ」は仮です。正式案を出してください。

派生（任意）

- 180 / 120 など iPhone 用一式があれば実装が楽
- 単色（ホーム画面用）があればなお良い

## 4. スプラッシュ（起動画面）

短い起動の間だけ出ます。機能説明を書かない。

必須

- カロナビのマークまたはロゴ
- 背景（単色またはごく薄いパターン）
- ロゴ位置（中央）
- Safe Area を侵さないこと

任意

- タグライン「毎日の食事と運動を、やさしく見える化。」
- ライトのみで可

禁止

- AYG
- ログインボタン
- 「読み込み中」以外の操作 UI
- 広告・キャンペーン

書き出し

- iPhone 用。390×844 クラスを 1 枚以上
- 可能なら 393×852、430×932 など主要サイズ
- PNG または Figma フレームで書き出し可能な状態

## 5. App Store スクリーンショット

審査と店頭用です。**実機の UI を切り抜く前提で、デザイン側が構図を決める。**

### 枚数とサイズ

最低 1 セット（iPhone 6.7" または 6.9" 系）。できれば次の 2 セット。

| セット | ピクセル目安 |
| --- | --- |
| 6.7" / 6.9" | 1290×2796 または現行の App Store 指定 |
| 6.1" | 1179×2556 など現行指定 |

Apple の最新サイズ表に合わせてください。サイズが変わっていても「iPhone 優先の縦長 2 セット」で足りません。

枚数目安：**5 枚**（3〜8 枚の範囲）。動画は不要。

### 5 枚の内容（推奨）

1. ホーム — 今日あと何kcal が主役
2. 食事追加 — 手入力と、カメラ＋番号のバーコードが同時に見える
3. 運動 — MET または手入力kcal
4. 体重 — 一覧（準備中と書かない）
5. 目標または設定 — 減量／維持／増量と、医療アプリではないこと

各枚に短い日本語キャプションを載せてよい。例

- 今日、あと何kcalか。
- 食事は、打つ・撮る・選ぶ。
- 運動は、選ぶか、kcal を入れる。
- 体重も、一覧で残す。

### 禁止

- AYG を店頭画像に出す
- 「治療」「診断」「医師推奨」
- 課金・広告・存在しない機能
- 英語だけのキャプション
- 体重タブを「準備中」で出す
- 実在する他人の顔写真（ストックは可だが、医療現場写真は避ける）

掲載文の草案は [../store/APP_STORE_LISTING.md](../store/APP_STORE_LISTING.md) です。スクショ用コピーと揃えてください。
