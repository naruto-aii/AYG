このファイルだけで、運動入力のデザイン対応を完了できます。  
Slack や口頭の補足は不要です。ここに無い項目は足さないでください。

| 項目 | 内容 |
| --- | --- |
| プロダクト | カロナビ（リポジトリ名 AYG は出さない） |
| 対象画面 | 運動を追加 / 運動を編集。関連：運動タブ、ホーム「今日の運動」 |

## 0. Claude / デザイナーへの依頼

運動入力の機能を更新した。現行の仮 UI を、下の仕様を崩さずに整えてほしい。

やってほしいこと

1. Preview で運動追加を一通り触る（歩き・筋トレ・家事・その他・編集・削除）
2. このファイルの項目・出し分け・コピーを正として、iPhone 向けフレームを描く
3. 空 / エラー / 種目別の出し分け / 詳細設定 / 削除確認を全部描く

やらないこと

## 1. なぜこうなっているか

ユーザーに聞くのは 3 つだけにする。

1. **何をしたか**（種目を 1 回）
2. **どれだけか**（時間。筋トレだけ任意でセット / 回数 / 重量）
3. **いくらか**（追加消費 net の 1 数字）

以前は「運動名」「種類」「種目」「表示名」「消費kcal」が同じことを何度も聞いていた。  
種類は裏の分類、表示名は例外だけ、kcal 手入力は詳細設定へ移した。

## 2. 画面の役割

### 2.1 運動を追加 / 編集

フルスクリーン。AppBar タイトルは追加なら「運動を追加」、編集なら「運動を編集」。  
保存は画面下の主ボタン。編集時だけ副ボタン「削除」。

テンプレートの作成・保存・適用は、この画面には出さない。  
テンプレート一覧は運動タブの AppBar アイコンからのみ。

### 2.2 運動タブ

日送りの一覧。行は **表示名 / 時刻・分数 / 追加消費（net）kcal**。  
空：「この日の運動記録はありません」＋ 今日以前なら「運動を追加」。  
未来日は閲覧可、新規追加不可。

AppBar

- 履歴カレンダー
- 運動テンプレート（一覧へ。入力画面には出さない）
- 運動追加

### 2.3 ホーム「今日の運動」

行は **表示名 / 時刻 / 追加消費（net）kcal**。  
空：「登録された運動はありません」。  
タップで編集。削除は確認＋「元に戻す」。

ホームの「消費 kcal」集計も net の合計です。gross は出さない。

## 3. 運動追加の構成（上からこの順）

通常面に出すものだけを先に描く。詳細設定は折りたたみ。

```text
AppBar: 運動を追加 | 運動を編集

種目（必須。チップで 1 つ）
  ├ 歩き のときだけ → 「これは？」追加の運動 / いつもの移動
  ├ 家事・掃除 のときだけ → 生活活動の注意文
  └ その他（手入力）または「名前を変える」→ 表示名

きつさ（種目に応じた 2〜3 択。MET は出さない）

実施時間（分）（必須）

筋トレ のときだけ → セット・回数・重量（任意、折りたたみ可）

記録日時

追加消費（結果。編集しない。kcal の主役）

詳細設定（折りたたみ）
  メモ / 内部 MET / 計算に使用した体重 / 推定総消費（gross）
  / 手動消費カロリー補正 / 計算バージョン / 計算根拠・参考文献
  編集時だけ「再計算」

[保存]
編集時だけ [削除]
```

初期状態（新規）：種目未選択。時間・日時以外は種目を選んでから出す想定でよい。  
実装は種目未選択でも時間欄は出るが、デザインでは「種目 → 分量 → 結果」の順が分かればよい。

## 4. 種目カタログ（増やさない）

表示名はこの表が正。チップの並びもこの順。

| id | 表示名 | 裏の種類 | きつさ | 追加の出し分け |
| --- | --- | --- | --- | --- |
| `walk_brisk` | ウォーキング | 有酸素 | ゆっくり / ほどよい / きつい | 「これは？」必須 |
| `run_jog` | ランニング・ジョギング | 有酸素 | 同上 | なし |
| `cycle_road` | 自転車 | 有酸素 | 同上 | なし |
| `swim_lap` | 水泳 | 有酸素 | 同上 | なし |
| `strength_general` | 筋トレ | 筋力 | 軽め / ふつう / きつい | セット / 回数 / 重量（任意） |
| `basketball` | バスケットボール | スポーツ | 軽め / ふつう / きつい | なし |
| `yoga` | ヨガ・ストレッチ | 日常 | 軽め / ふつう | なし。生活活動の警告は出さない |
| `housework` | 家事・掃除 | 日常 | 軽め / ふつう | 注意文のみ |
| `custom` | その他（手入力） | その他 | 軽め / ふつう / きつい | 表示名を必須で出す |

種類チップ・検索ボックスは出さない。種目が増えるまで検索は不要。

### 4.1 表示名

- カタログ種目：選んだ表示名が記録名になる。通常面には出さない
- 「名前を変える」を押したときだけ、表示名フィールド
- 「その他（手入力）」は最初から表示名必須

## 5. 項目の意味と出し分け

### 5.1 歩き「これは？」

| 選択肢 | 意味 | 追加消費 |
| --- | --- | --- |
| 追加の運動 | 意図した運動。残りカロリーに入れる | 自動計算の net |
| いつもの移動 | 通勤など。生活活動係数に含まれる | **0** |

補助文（いつもの移動を選んだとき）

> 通勤などのいつもの移動は生活活動係数に含まれているので、追加消費には入れません。

初期値は「追加の運動」。

### 5.2 家事・掃除の注意（警告ではない）

> いつもの家事は、設定の生活活動係数にすでに含まれています。特別に長く動いた分だけ記録してください。

ヨガ・ストレッチには出さない。

### 5.3 きつさ

主観の 2〜3 択。内部 MET は通常面に出さない。  
手動補正 ON のときは選択不可（見た目で無効と分かるように）。

有酸素（歩き・走り・自転車・水泳）の説明（チップに出さなくても、デザイン注記で残す）

| ラベル | 説明 |
| --- | --- |
| ゆっくり | 会話を楽に続けられる |
| ほどよい | 会話はできるが少し息が弾む |
| きつい | 短い言葉しか話せない |

筋トレ

| ラベル | 説明 |
| --- | --- |
| 軽め | フォーム練習、軽い重量、余裕を持って続けられる |
| ふつう | 適度にきついが、まだ数回は続けられる |
| きつい | 高重量や短い休憩で、かなりきつい |

### 5.4 実施時間（分）

必須。1 以上の整数。  
消費カロリーは時間から計算する。筋トレのセット数では計算しない。

筋トレの折りたたみタイトル「セット・回数・重量（任意）」  
サブ「消費カロリーは実施時間から計算します」

| 項目 | 必須 | 型 |
| --- | --- | --- |
| セット | 任意 | 整数 |
| 回数 | 任意 | 整数 |
| 重量（kg） | 任意 | 小数可 |

### 5.5 追加消費（通常面の結果）

見せる数字は **net だけ**。残りカロリーに加算される分。

補助文

> 残りカロリーに加算される、運動による追加分

歩きで「いつもの移動」のときは 0 と、5.1 の補助文。

体重が無く自動計算できないとき（エラー色でよい）

> 体重データがないため、消費カロリーを自動計算できません。体重を記録するか、手動で入力してください。

### 5.6 詳細設定（折りたたみ。通常面に出さない）

| 項目 | 扱い |
| --- | --- |
| メモ | 任意。複数行 |
| 内部 MET | 参照のみ |
| 計算に使用した体重 | 参照のみ |
| 推定総消費（gross） | 参照のみ。「運動時間中の総エネルギー消費」 |
| 手動消費カロリー補正 | スイッチ。ON で「手動 追加消費 kcal（net）」を手入力 |
| 計算バージョン | 参照のみ |
| 計算根拠・参考文献 | 既存の根拠画面へ |
| 再計算 | **編集時だけ**。保存済みの数字を、今の入力と体重でやり直す |

手動補正は net の上書き 1 つだけ。gross の手入力欄は作らない。

編集時の注記

> 保存済みの計算結果を、現在の入力内容と体重データで再計算します。

## 8. 見た目で解いてほしいこと

機能は足りている。仮 UI の使い勝手を整える。

1. **3 問に見えること**  
   種目 → 分量 → 追加消費。詳細は一段下げて目立たせない。
2. **種目 9 個の選択**  
   今は ChoiceChip の Wrap。押しやすく、選中が分かること。検索は足さない。
3. **追加消費を結果として見せる**  
   入力欄に見えないこと。編集できない数字。ホームの「今日あと何kcal」と意味がつながること。
4. **歩きの 1 問**  
   「追加の運動 / いつもの移動」が、きつさや種目と別質問だと分かること。
5. **筋トレの任意項目**  
   セット類は日誌。kcal の主役にしない。
6. **詳細設定**  
   開けば分かるが、通常面を長くしない。MET をヒーローにしない。
7. **一覧行**  
   名前と追加消費（net）。gross や MET を行に出さない。

デザイン原則（カロナビ共通）

- 外はシンプル。内部計算は見せない
- 入力は最小。忙しい会社員が毎日続けられること
- 医療アプリに見せない。責めない
- 日本語の日常語。MET / gross / net は詳細とこの資料の中だけ

## 11. 古い資料との差分

全体のデザイナー向け IA（[PR #1](https://github.com/naruto-aii/AYG/pull/1) の `docs/design/01_INFORMATION_ARCHITECTURE.md` 7 章）は、この更新より前の記述が残っています。**運動入力は本ファイルを正**にしてください。

| 古い IA | 現行 |
| --- | --- |
| MET ルートと手入力kcal の 2 通り | 種目 1 回＋自動計算。手入力は詳細の net 上書きだけ |
| 種類 → 種目 → 強度 | 種目チップだけ |
| 通常面にテンプレート保存 | 運動タブのテンプレート一覧のみ |
| 筋トレ総合 / マシン | 「筋トレ」1 つ |
| 一覧が gross でもよい | 一覧・ホームは net |

## 12. Preview での確認手順

1. https://naruto-aii.github.io/AYG/ を開く（古い画面ならハードリロード）
2. ログイン済みなら下タブ「運動」→ 追加
3. ウォーキング → 「追加の運動」と「いつもの移動」を切り替えて追加消費を見る
4. 筋トレ → セット折りたたみと、kcal が時間ベースなことを確認
5. 家事・掃除 → 注意文。ヨガ・ストレッチ → 注意文が無いこと
6. その他（手入力）→ 表示名
7. 保存後、運動タブとホームの数字が追加消費と一致すること
8. 編集 → 詳細設定 → 再計算 / 削除 → 元に戻す
