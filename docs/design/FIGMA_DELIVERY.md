## Figma の「Code」について

Figma 右サイドの Code / Inspect は、色・文字サイズ・余白の **数値（CSS）** です。iPhone アプリの Dart コードそのものではありません。こちらはその数値を読んで Flutter に組み立てています。1ボタンでアプリになる機能ではありません。

画面ごと・部品ごとに数値を当てると、見た目はフレームにかなり近づけられます。端末のノッチ、文字サイズ設定、OSのフォント描画で 1px 単位の完全一致にはなりません。

## この更新で近づけたこと

- 日本語の行間を潰さない（文字が欠けて化けて見える対策）
- フォントが読めないときの日本語フォールバック
- Figma の線アイコンを書き出して使用
- 下タブをオレンジ帯・中央ホーム・選択の緑丸に
- ログインの配置とボタン高さをフレーム値に
- ホームから Figma に無い「今日のサマリー」を外した

- 色・文字・ログイン・ホーム・設定・初回設定・下タブを納品に寄せた
- 運動の通常面からテンプレートを出さない（Slack承認の3問構成のまま）
- カロナビ+ の価格と無料枠は変えない
- 利用規約・プライバシーのリンクはログインと設定に残す
