# カロナビ デザイン資料

納品ファイルは Figma `カロナビ - Design System & Screens`（2026-09-20）。  
読み取った内容と実装方針は [FIGMA_DELIVERY.md](./FIGMA_DELIVERY.md)。参照画像は `figma/`。
