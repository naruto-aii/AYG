今日、あと何kcalか。

食事・運動・体重をまとめて、毎日の次の一手を短くするエネルギー管理アプリ「カロナビ」

  1. 今日の判断が主役 — 「今日あと何kcal」とPFCの目安
  2. 入力は最小 — 手入力・バーコード（カメラと番号）・テンプレート
  3. 記録で終わらない — エネルギー収支から次の行動へ

カロナビ+（任意）— 公開食品検索やテンプレートの上限を拡大。料金は公開時の購入画面が正です。
