食事カロリーと次の行動判断

カロナビ

食べたもののカロリーを把握して、その日の次の行動を決めるためのアプリです。

できること

  • 食事のカロリーを、その日の単位で見られます。
  • 食べたあとに、次はどうするかの目安を短い言葉で示します。
  • 毎日開く前提で、入力と画面は単純にしてあります。
  • 計算はアプリの中で行い、見る人には行動の目安が残るようにします。

カロナビ+

カロナビ+は、カロナビの有料プラン（サブスクリプション）です。基本のカロリー把握と次の行動の目安で足りる方は、無料のまま使えます。＋では、もう少し先まで見通したい方に向けて、必要な機能だけを足す予定です。

料金と含まれる内容は、公開後にアプリの中で確認できます。リリース前のため、いま申し込むことはできません。
