# 食品成分表 表示名・読み・別名の見本（50件）

正式名称は本番の `official_foods.name` を空白整理しただけです。
display_name と読みと別名は下書きで、本番には入れていません。
読みの長音を除いた検索キーが `search_reading` です。
ぎゅうどん / ギュウドン / 牛丼は、別名「牛丼」（読み ぎゅうどん）の候補に揃います。
