# Siri の名寄せ

Siri は話し言葉なので、アプリに打つ検索より揺れが大きい。食品も運動もテンプレート名も、次の同じ手順で決める。Dart の `pickSiriMatches` と Swift の `isObvious` はこの順を守る。食品成分表の順位そのものは、アプリ内の `search_official_foods` と同じである。

## 揺れの種類

- ひらがな、カタカナ、漢字、全角と半角、長音の有無。これはアプリ内検索の正規化で吸収する。
- 音声認識の言い間違いに近い呼び方。`とりむね`、`むね肉`、`胸肉` は若鶏むね（皮なし・生）の別名にする。`散歩` はウォーキング、`筋トレ` はウェイトトレーニング、`ラン` はランニング、として扱う。
- 助詞の混入。`鶏のむね` のように間へ入った `の` `を` `は` `が` を除いた形でも照合する。
- 量と名前が続いた言い方。`ささみ100g`、`納豆1パック`、`散歩した` は、名前と量に分けてから照合する。

公開食品は Siri の対象にしない。記録したいものはテンプレートにする。

## 照合の順番

1. テンプレート名、保存済み食品、食品成分表、運動の順で候補を集める。保存済み食品が1件でも当たれば、成分表よりそちらを使う。
2. 各候補は完全一致、前方一致、部分一致の段に分ける。2文字以下は完全一致だけを見る。`ささ` で `ささみ` を採らない。
3. 同じ段では、確定した別名を候補より前に、候補の順位、優先度、食品番号の順に並べる。成分表の検索と同じである。
4. 運動の話し言葉（散歩、ウォーキング、ジョギング、ラン、筋トレ、自転車）は、別名が複数の種目に付いていても代表の1件にする。

## 候補の選ばせ方

先頭が次より明らかに良いときは、確認せずその1件を登録し、「ささみ100gを登録しました」と読む。明らかに良いとは、段が上であるか、確定した別名が候補より前にいることである。同じ食品で生・ゆで・皮の違いだけのときも聞かず、よく食べる形にする。`ささみ` は若鶏ささみ（生）、`鶏むね` は皮なしの生、`白菜` は生である。

別の食品がいくつも残って、質問が尽きたときと、「わからない」のときは、自信が低い。そのときだけ「でいいですね」と確認してから登録する。毎回は確認しない。

2件か3件の別食品は、その名前を読み上げて選ばせる。部位や種類が大きく分かれて、読み上げると長くなるときだけ質問する。肉は部位、魚や野菜は種類を、一つだけ短く聞く。質問は3回まで。「もも」「焼いたやつ」のように話した答えで候補を減らす。「わからない」「普通の」「何でもいい」は、その場のよく食べる形にし、確認してから登録する。「やめる」「キャンセル」で終わる。

「牛ももの焼き200g」のように詳しく言えば、質問せず登録して内容を読む。牛肉のように大まかだと、部位を聞くことがある。量が無いときと、量が曖昧なときは、これまでどおり g を聞く。

登録のあと、Siriの質問への答えとして「さっきの登録を取り消して」「今登録したやつ消して」と言うと、直前の1件だけ取り消す。これは単独のショートカットではない。食事も運動も同じ。「ささみ100gの登録を取り消しました」と読む。もう一度言うと、取り消す登録は無い。

テンプレート名が完全一致したときは、そのテンプレートの中身で登録する。食品名も同じ完全一致なら、テンプレートか食品かを選ばせる。

## 0件のとき

`見つかりません` で終わらない。もう一度言うよう聞き、それでも無ければ検索語をアプリに残して開く。食事なら食品の名前欄、運動なら種目名にその語が入る。

## 量の聞き返し

`大盛り`、`少なめ`、`半分`、`1杯`、`1パック`、`ちょっと`、`した` のようにグラムや分が決まらないときは、登録の前に聞く。食品は `何gですか？`（ml や個の食品は、その単位）。運動は `何分ですか？`。答えの数字で記録する。

ウォーキング、ジョギング、ランニングは、これまでどおり km でも、分でも記録できる。分のときは MET と時間と体重で消費を計算する。
