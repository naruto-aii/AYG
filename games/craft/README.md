# テラブロック

ブラウザで遊べる一人称のボクセルサンドボックスです。公開ページでは `/craft/` に置きます。

テクスチャ、効果音、UI はすべてこのゲーム用に描いたものです。他社のテクスチャ、ロゴ、フォント、名称は使っていません。見た目は 16×16 のドット絵、近傍補間、ブロックごとの近い色味（草の上面と側面、土、石、丸石、板材、原木、葉、砂、水、鉱石など）に揃えています。

## 遊び方

- **サバイバル**: 体力と空腹があります。木を壊し、インベントリの 2×2 で板材や作業台を作ります。
- **クリエイティブ**: 即破壊、飛行、ブロック一覧から取れます。
- **つづきから**: このブラウザに保存した世界を開きます（IndexedDB）。

### スマートフォン

画面左のスティックで移動、画面のドラッグで視点、右のボタンでジャンプ・破壊・設置・しゃがみ・飛行・インベントリ・一時停止です。

## マルチプレイ

サーバーは立てません。部屋を作った端末がホストになり、公開の MQTT リレー（HiveMQ / EMQX）で WebRTC の接続情報だけを交換します。地形は同じシードから各自が生成し、壊した・置いたブロックを同期します。

1. ホストが「なかまと遊ぶ」から部屋を作る。
2. 表示された 6 文字のコード、またはコピーしたリンク（`?room=コード`）を渡す。
3. 参加する人はそのコードを入れて「参加する」。

制限:

- ホストの画面を開いたままにしてください。ホストが離れると世界の権威が止まります。
- リレーに届かないネットワークでは部屋が成立しません。一人用はそのまま遊べます。
- 水は流れません。砂と砂利は置いた列ですぐ下まで落ちます。
- レッドストーン、エンチャント、経験値、防具、バケツはありません。
- 葉は葉ブロックではなく棒か、まれにリンゴを落とします。ガラスはそのまま落ちます。
- 生き物はウリボウと夜の歩行者の 2 種です。ホストが動かします。

## 開発

```bash
python3 -m http.server 8765 --directory games/craft
node --test games/craft/test/logic.test.mjs
```

Pages への配置は `tool/assemble_pages_site.sh` が `games/craft` をサイトの `craft/` にコピーします。
