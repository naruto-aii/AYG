# VP音声通話（試作）

カロナビの本番アプリとは別に置いた、音声の打ち合わせ試作品です。このディレクトリ以外は変えていません。本番の Supabase にも、Cursor のクラウドエージェントにも、出していません。

## 動かし方

鍵の値はこのリポジトリに書きません。起動するシェルに、名前だけ合わせて入れてください。

- `ANTHROPIC_API_KEY` … 返事を考える Claude の鍵
- `CURSOR_API_KEY` … 承認した依頼を Cursor の Cloud Agents API に出す鍵。打ち合わせだけなら空でよい
- `SETUP_TOKEN` … 最初にパスワードを決めるときだけ使う合言葉。常設の `APP_PASSWORD` はありません。長い無作為な文字列を、Vercel の環境変数に入れてください
- `BLOB_READ_WRITE_TOKEN` … Vercel に出すとき、パスワードのハッシュを残す非公開 Blob の鍵。手元だけで動かすときは不要です

```sh
cd prototypes/vp-voice
node relay/server.mjs
```

Chrome で http://127.0.0.1:8787 を開きます。待ち受けは `127.0.0.1` だけです。

初めて開いた画面で、合言葉（`SETUP_TOKEN`）とパスワードを決めます。パスワードは scrypt でハッシュし、合言葉そのものは保存しません。決めたあとは、その画面は出ません。次からはパスワードだけです。ログインは署名付きの Cookie で保持します。5回続けて間違えると15分ロックします。忘れたときは、Vercel の `SETUP_TOKEN` を別の値に入れ替えてから開き直し、新しいパスワードを設定します。

パスワードの記録は、Vercel Blob の非公開オブジェクト1つ（`vp-voice/auth.json`）です。失敗回数も同じ場所に上書きするので、読み取り向けの Edge Config より向いています。本番の Supabase に表やスキーマを足すとカロナビのデータベースを触ることになるので、使いません。Blob は上書きの直後にキャッシュが残ることがあるため、読むときはキャッシュを外し、etag が食い違ったら書き直します。手元で Blob の鍵が無いときは `data/auth.json` に同じ形で書きます。このファイルは git に入れません。Vercel 上で Blob の鍵が無いときは、一時ディスクには書かず、設定できないようにしてあります。

1. 「打ち合わせを始める」を押す。
2. マイクがオンなら、そのまま話す。音声認識が使えないときは下の欄に書いて送る。
3. 終えるときは「打ち合わせを終わる」。議事録が出るので、ダウンロードできる。

モデルの標準は Haiku（`claude-haiku-5-5`）です。Sonnet にも切り替えられますが、30分10円の予算には収まりません。

中継は `relay/server.mjs` です。Anthropic と Cursor の鍵は、そのプロセスの環境変数から読みます。ブラウザには渡しません。

同じ処理の入口を `supabase/functions/vp-voice/index.ts` に置いてあります。リポジトリ直下の `supabase/functions` には入れていません。デプロイしません。手元で Edge Function として動かすときも、鍵は `ANTHROPIC_API_KEY` と `CURSOR_API_KEY` という環境変数名で読みます。リポジトリを読ませるときは `VP_REPO_ROOT` に作業ツリーのパスを入れます。

## Vercel

プロジェクトはまだ作っていません。デプロイもしていません。出すときは、このリポジトリの Root Directory を `prototypes/vp-voice` にしてください。

| 設定 | 値 |
| --- | --- |
| Root Directory | `prototypes/vp-voice` |
| Framework Preset | Other |
| Node.js | 22.x |
| Build Command | `node scripts/stage-public.mjs`（`web/` を `public/` にコピーするだけ） |
| 関数 | `api/` 以下の各パス。Node.js。`maxDuration` は 120 秒。中身は `relay/http.mjs` を呼ぶだけです |
| Fluid Compute | オン（新規プロジェクトの標準） |
| Plan | Hobby で足ります。1回の返事は 120 秒以内で、Hobby の上限は 300 秒です。30分の打ち合わせは、この関数を30分動かし続けるのではなく、短い呼び出しの繰り返しです |
| メモリ | `vercel.json` には書きません。Fluid Compute ではダッシュボードの指定です。Hobby は 2GB / 1 vCPU 固定です |

環境変数は、値をリポジトリにもブラウザにもログにも書きません。名前だけ読みます。常設の `APP_PASSWORD` はありません。

| 名前 | 用途 |
| --- | --- |
| `ANTHROPIC_API_KEY` | Claude の鍵。必須 |
| `CURSOR_API_KEY` | 承認した依頼を Cursor に出す鍵。打ち合わせだけなら空でよい |
| `SETUP_TOKEN` | 最初のパスワードを決めるとき、または忘れて入れ替えるときの合言葉。必須 |
| `BLOB_READ_WRITE_TOKEN` | パスワードのハッシュと、打ち合わせの下書きを残す非公開 Blob。本番と Preview では必須。`vercel dev` では空でよく、そのときは手元の `data/` に書きます |
| `VP_ANTHROPIC_BASE_URL` | 任意。Claude の送り先。空なら `https://api.anthropic.com` |
| `VP_CURSOR_BASE_URL` | 任意。Cursor の送り先。空なら `https://api.cursor.com` |
| `VP_REPO_ROOT` | 任意。リポジトリを読む起点。空なら、デプロイの中で見つかる範囲です |

本番と Preview で Blob の鍵が無いときは、一時ディスクにパスワードを書かず、設定できないようにしてあります。`/api/auth/status` と `/api/auth/setup` と `/api/auth/login` だけは、ログイン前でも届きます。それ以外の `/api/*` は、署名付き Cookie が無いと 401 です。間違いは 5 回で 15 分ロックします。Cursor への送信は、これまでどおり声の「それでいい」と画面の承認が揃ったときだけです。下書きは Blob（手元では `data/sessions/`）に残すので、関数のインスタンスが変わっても承認を通せます。

サイト上でリポジトリを読む範囲は、デプロイに入ったファイルだけです。Root Directory の外にあるカロナビ本体は同梱しません。秘密のファイルを配信物に混ぜないためです。

## できること

- 日本語の自由な会話。聞き取りと読み上げはブラウザの Web Speech API。追加の音声APIは使いません。
- 返事はストリーミングで受け、文ごとに読み上げを始めます。相手が話し始めたら読み上げを止めます。
- 声は、入っている日本語の音声のうち女性名に近いものを選び、高さと速さを上げています。
- VP は添付の絵そのものです。絵は部品（後ろ髪、体、顔、目、まぶた、口、前髪）に分けてあります。画面では、隙間で絵が割れないように元の絵を一枚のメッシュとして曲げ、開いた口だけをその上に重ねています。まばたきは、元のまつ毛とまぶたの画素を下へずらして補間します。呼吸、髪、顔の向き、うなずき、口は、これまでどおり経過時間で補間します。口は読み上げ中の文字の母音に合わせて、開き具合を連続的に変えます。追加のAPIは使いません。
- リポジトリは全体を渡しません。聞かれたときだけ `read_repo` で必要なファイルを読みます。`.env` や `tool/dart_defines.local.json` など秘密のファイルは読みません。
- 画面に経過時間、入出力トークン、概算費用（円）を出します。7円に近づくと節約モードになり、Haiku、短い返事、ファイルを開かない、に切り替えます。予算は打ち合わせあたり10円です。
- 終了すると議事録（要点、決まったこと、宿題、Cursorに出した依頼）を作り、ダウンロードできます。
- Cursor への依頼は、VPが文面を出して「依頼はこの内容でいい？」と確認します。声で「それでいい」と言い、画面の「この内容で承認する」を押したときだけ `POST /v1/agents` を呼びます。どちらか一方では送りません。起動したエージェントの URL を画面と議事録に残します。送る先は `https://github.com/naruto-aii/AYG` の `main` を起点にした新しいブランチで、PR を作る設定です。`main` へ直接は載せません。この試作品の確認では、本物の API は呼んでいません。

## 30分の費用

為替は 1ドル150円の概算です。単価は Anthropic のリスト価格（2026-10-07）です。

| モデル | 入力 | 出力 | キャッシュ作成 | キャッシュ読 |
| --- | --- | --- | --- | --- |
| Haiku 5.5 | $0.10 | $0.50 | $0.125 | $0.01 |
| Haiku 4.5 | $1 | $5 | $1.25 | $0.10 |
| Sonnet 5.5 | $2 | $10 | $2.50 | $0.10 |

単位は100万トークンあたりです。Haiku 5.5 は入力10万トークン以下の単価です。

想定する30分:

- 往復 40回（約45秒に1回）
- システムとツール定義 1,250トークン。初回だけキャッシュ作成、以降はキャッシュ読
- 各回の新しい入力 330トークン（古い会話は短い要約にして、直近だけ残す）
- リポジトリは 6回、抜粋 800トークン。全体は渡さない
- 出力は返事 70 と、低めの思考 80 で、1回 150トークン
- 終わりの議事録（入力 1,200、出力 500）と、依頼の下書き 2件

この想定だと Haiku 5.5 は 0.91円です。キャッシュが効かず、毎回出力の上限 180 トークンまで使っても 1.65円で、10円に収まります。

同じ想定の Sonnet 5.5 は 17.4円、上限まで使うと 33円です。10円には収まりません。Haiku 4.5 も、上限まで使うと 16.5円で収まりません。標準は Haiku 5.5 にしてあります。

画面の円は、応答に含まれる入力・出力・キャッシュ作成・キャッシュ読のトークンを、上の単価でその場で足したものです。思考トークンは出力に含まれます。出力の上限を 180（節約中は 80）にしているので、思考が膨らんでもその回数の出力はその数を超えません。

## 弱点

- 音声認識は Chrome が Google のサーバーへ音声を送ります。使えない環境では、文字で送る欄を使います。
- 声の可愛さは、端末に入っている日本語音声と、高さ・速さの調整次第です。
- スピーカーだと、読み上げや相槌をマイクが拾うことがあります。イヤホンの方が安定します。
- 開いた口は、元の絵にない部分を色に合わせて描き足しています。大きく開くと筆致は元の絵そのものにはなりません。まばたきは元のまつ毛をずらすので、閉じた線は元の太さと色です。ブラウザは読み上げの波形を渡さないので、口は話している文の文字のタイミングに合わせています。漢字は母音が取れず、その文字のあいだは緩い開閉になります。
- 髪や体は平面のメッシュを曲げているので、横を向く立体ではありません。揺れと奥行きのずらしです。
- 秘密ファイルはパスで除外し、鍵に見える行は伏せますが、普通のファイルに秘密が混ざっていれば、その行の形によっては残ることがあります。
- 概算の円は 1ドル150円の固定です。請求はドルで、キャッシュが外れると少し増えます。
- パスワードを忘れると、`SETUP_TOKEN` を入れ替えるまで戻せません。入れ替えてから設定し終えるまでは、新しい合言葉を知っている人がパスワードを決められます。
- `127.0.0.1` 以外へ公開すると、パスワードを通った人が Claude の鍵を消費できます。中継自体に利用者ごとのアカウントはありません。
- Vercel に出したとき、VP が読めるリポジトリはデプロイに入ったファイルだけです。カロナビ本体のソースは含まれません。
